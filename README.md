## 🧩 주요 기능

- ✅ Todo 항목 추가 및 삭제
- 🔍 키워드로 실시간 검색
- 🗓️ 작성 날짜 표시
- ✔️ 체크박스로 완료 상태 표시

## 📚 React 공부 포인트

- `useState`, `props`, `map()` 사용하여 동적 렌더링 구현
- 조건부 렌더링 (`checked`, `filter`)
- 컴포넌트 분리 (`TodoItem`, `List`, `Editor`)
- CSS로 사용자 친화적인 UI 구현 (flex 정렬, transition 효과 등)
